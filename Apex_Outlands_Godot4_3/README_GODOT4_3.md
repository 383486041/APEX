# APEX 英雄：外域协议 (Godot 4.3 3D 完整精修版)

本工程为 **纯正 Godot 4.3 (Forward+)** 3D 战术竞技工程，已移除所有 HTML/WebGL 网页版文件，并针对你反馈的 **视角控制、枪械精细模型、多阶段换弹动作、近战与传家宝连段、传奇全技能系统** 进行了全面重构与精细化升级。

## 一、 核心升级与修复清单

1. **修复 Godot 4.3 视角控制与鼠标锁定 (`PlayerController.gd` & `MatchScene.gd`)**
   - 修复了原版全屏 `Control` 节点默认 `MOUSE_FILTER_STOP` 拦截鼠标事件导致 `_unhandled_input` 失效的问题；现所有 HUD 层均设为 `MOUSE_FILTER_IGNORE`，并在 `_input()` 中直接处理高精度鼠标视角旋转。
   - 支持 **点击画面自动锁定准星 (`MOUSE_MODE_CAPTURED`)**、**按住鼠标左/右键拖拽旋转视角**，以及 **键盘方向键 (`↑/↓/←/→`) 备用视角旋转**，在任何环境下均可流畅 360° 操控视角。
   - 修复了 Godot 4.3 中 `DirectionalLight3D` 未入树前调用 `look_at_from_position` 报错的问题。

2. **多部件高精度 3D 枪械与第一人称战术手臂 (`WeaponMeshBuilder.gd`)**
   - 摒弃原有的简单方块，每把武器均由 **25+ 个独立 3D 部件与金属/发光 PBR 材质** 组装而成：
     - **上下机匣 (`UpperReceiver` / `LowerReceiver`)**：带抛壳窗、斜面装甲护板、扳机护圈、人体工学握把。
     - **散热护木与皮卡汀尼导轨 (`Handguard` & `Picatinny Rail`)**：带散热开孔、步进式导轨齿。
     - **枪管、导气箍与定制枪口制退器 (`Barrel` & `MuzzleBrake`)**：按步枪/冲锋枪/狙击枪/霰弹枪差异化建模，配星形 3D 枪口火焰 (`MuzzleFlashNode`) 与动态点光源。
     - **可拆卸动画弹匣 (`MagPivot`)**：弧形弹匣（带透明观弹窗）、能量电池核心、机枪弹鼓、小帮手左轮摆出式转轮。
     - **可往复枪机拉柄/狙击枪栓/杠杆 (`BoltPivot`)**：开火自动后坐往复，空仓换弹或栓动狙击/和平捍卫者开火后执行拉栓/转枪上膛动作。
     - **模块化 3D 瞄准镜 (`OpticPivot`)**：1x 全息、2x 格斗家、1x 数字化威胁、6x-10x 重狙双筒光学镜（含半透明镀膜镜片与发光准星）。
     - **机匣尾部 3D 数字弹药屏 (`AmmoLabel3D`)**：实时显示当前弹匣余量与 `RLD` 换弹状态。
     - **第一人称战术装甲手臂 (`LeftArmPivot` / `RightArmPivot`)**：护臂、战术腕表与手套，随换弹与近战同步运动。

3. **三阶段拟真换弹动画与拉栓上膛动作 (`WeaponController.gd`)**
   - **阶段 1（0%~32% 卸下弹匣）**：枪身左倾 30°，左手抓握弹匣将其拔出，空弹匣物理抛落至地面，触发 `mag_out` 音效。
   - **阶段 2（32%~68% 插入满弹匣）**：左手从腰间取出满弹匣推入弹匣井，伴随机身向上顿挫反馈与清脆的 `mag_in` 卡扣音效。
   - **阶段 3（68%~100% 拉栓推弹上膛）**：枪身右倾，左手拉动侧边拉机柄/狙击枪栓/左轮转轮复位，触发金属 `bolt_slap` 音效。
   - **单发拉栓/杠杆转枪动作**：克雷贝尔、哨兵狙击枪与和平捍卫者每次开火后自动播放拉栓/杠杆退壳动作。
   - **360° 武器/传家宝检视 (`N` 键)**：按下 `N` 键可翻转检视枪械两侧细节，或持续旋转把玩传家宝。

4. **神话传家宝近战系统 (`3` 键) 与快速近战 (`V` 键)**
   - **按 `3` 键拔出传奇专属 3D 传家宝**：
     - **恶灵【希望之暮 苦无】**：尾部指环、缠柄、护手、四棱锥刃与紫色虚空等离子刃口。
     - **动力小子【辛烷蝴蝶刀】**：双钛合金镂空刀柄（内置绿色兴奋剂管）与翻转刀刃。
     - **寻血猎犬【渡鸦之咬战斧】**：北欧符文长柄、渡鸦背刺与熔岩红战斧刃。
   - **三段式近战挥砍连招**：手持传家宝按左键依次触发 **右斜劈 -> 左上挑 -> 360° 回旋重劈（附带 3D 弧形刀光波与击退）**。
   - **快速近战 (`V` 键)**：持枪状态下按 `V` 键立即向前突进挥出近战重击（35 伤害 + 击退）。

5. **全 12 位传奇被动、战术 (`Q`) 与终极 (`Z`) 3D 技能系统 (`AbilitySystem.gd`)**
   - **恶灵**：被动虚空低语瞄准预警 | `[Q] 踏入虚空`（4秒无敌+紫幕滤镜+35%加速） | `[Z] 维度裂隙`（生成起点与终点双向 3D 传送门，踩入即瞬移）。
   - **动力小子**：被动高速回血 | `[Q] 兴奋剂`（绿幕狂飙+35%移速+换弹加速） | `[Z] 弹射跳垫`（生成 3D 物理跳垫，踩踏高空弹射+二段跳）。
   - **寻血猎犬**：被动渡鸦距离追踪 | `[Q] 上帝之眼`（释放 90m 3D 橙红声呐球，穿墙红框透视高亮所有敌人） | `[Z] 狩猎野兽`（18秒红影狂猎模式，击杀回血延长时间）。
   - **探路者**：`[Q] 机械钩爪`（发射 3D 钢缆钩爪执行大摆锤飞跃） | `[Z] 滑索枪`（架设 3D 高空钢缆滑索，按 `E` 挂载高速滑行）。
   - **命脉**：空中按住 Space 无人机滑翔 | `[Q] D.O.C. 治疗无人机`（召唤 3D 悬浮医疗机持续回血回盾） | `[Z] 医疗光环护盾`。
   - **直布罗陀 / 邦加罗尔 / 地平线 / 艾许 / 瓦尔基里 / 侵蚀 / 幻象**：开镜 3D 臂盾 + 6.5m 保护圆顶 + 重炮轰炸 + 三联烟雾墙 + 18m 反重力电梯 + 黑洞奇点吸附 + 电弧束缚陷阱 + 38m 相位剑闪 + VTOL 喷气飞行 + 夜神毒气陷阱 + 全息诱饵分身。

## 二、 运行方式与键位说明

1. 打开 **Godot Engine 4.3**，点击 **导入 (Import)**，选择本项目文件夹内的 `project.godot`，点击 **运行项目 (F5)**。
2. **局内操作键位一览**：
   - `W / A / S / D`：移动 | `Shift`：冲刺 | `Shift + C / Ctrl`：滑铲 | `Space`：跳跃 / 蹬墙跳 / 二段跳 / 瓦尔基里喷气飞行
   - `鼠标移动`（或 `方向键 ↑↓←→`）：360° 自由旋转视角
   - `鼠标左键`：开火 / 传家宝三段挥砍 | `鼠标右键`：开镜瞄准 (ADS)
   - `R`：三阶段拟真换弹 | `1 / 2`：切换主/副武器 | `3`：拔出神话传家宝 | `V`：快速近战重击 | `N`：360° 检视枪械/转刀
   - `Q`：释放传奇战术技能 | `Z`：释放传奇终极技能（大招）
   - `4`：使用当前恢复品 | `H`：切换恢复品（大电/小电/医疗箱/注射器/凤凰包） | `G`：投掷电弧星手雷 | `B`：武器过载充能
   - `E`：从靶场 22 把 3D 武器陈列架拾取换枪 / 开启补给仓 / 搭乘滑索
   - `F1 / F2`：激活蓝甲/紫甲传奇进化天赋 | `ESC`：解锁/锁定鼠标或返回主大厅
